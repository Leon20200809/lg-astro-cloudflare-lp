# ACTIVE.md

## 任務

「ホームページの役割」4カードを、意味が一目で伝わるデザインへ改善する。

## GOAL

信用・問い合わせ・採用・情報提供の4分類が、文章を読み込まなくても直感的に理解できる状態にする。

## 今回やる

- 4項目それぞれに意味の合うアイコンを付ける
- `01 / 02 / 03 / 04` の数字表現をデザイン要素として強化する
- カード内の視線順を整理する
- 必要なら本文を少しだけ簡潔にする
- 余白・枠線・アイコン背景などを微調整する

## 今回やらない

- セクション自体の目的変更
- 4項目の分類変更
- 問い合わせフォーム・API・Worker・Resendの変更
- 他セクションの大規模リファクタリング
- 派手なアニメーションや過剰な装飾

## デザイン方針

装飾を増やすのではなく、**分類の理解速度を上げる**。

法人向けLPの落ち着きと高級感は維持する。

アイコン例：

- 信用：盾 / チェック / 建物
- 問い合わせ：メール / 吹き出し / 電話
- 採用：人物 / 履歴書 / briefcase
- 情報提供：ドキュメント / info / 地図ピン

数字は単なる番号ではなく、`ROLE 01` や大きめの `01` など、カード構造を示す要素として扱う。

## 対象範囲

既存コードを確認し、この4カードを構成するコンポーネントとCSSだけを必要最小限変更する。

## 完了条件

- 4項目の違いが視覚的に理解しやすい
- PC/SPともにレイアウトが崩れない
- 既存のLP全体トーンを壊していない
- `build` が成功する
- `git diff --check` が成功する
- 任務外の差分がない
